Frontend Architecture — Angular 21

Standalone components · zoneless change detection · Signals state · lazy-loaded features (verified folder structure)

core/ — app-wide singletons

auth/AuthService (JWT decode + localStorage), AuthStore signals, functional guards, Bearer interceptor, login / forgot / reset pages, delete dialog
http/APP_CONFIG token · error interceptor → unified AppError · retry interceptor (GET-only, exponential backoff)
realtime/NotificationHubService (SignalR), reconnect handler → REST refetch, unread-badge store
layout/ + config/AppHeader (unread badge), role-aware collapsible AppSidebar, APP_CONFIG token

shared/ — reusable & stateless

styles/SCSS design tokens + mixins (colors, spacing, focus-ring, breakpoints)
ui/button · card · status-badge · empty-state · spinner · pagination
pipes / directives / validators / utilrelative-time, cairo-time (Africa/Cairo), autofocus, borrowing-period (1–30), toQueryParams

features/ — lazy-loaded domains

books/data (model · api · store) · pages (list, detail) · ui (card, search bar) — search, sort, availability filter, pagination
requests/data (model · api · store) · pages (my requests, admin review) · ui (row, borrow form, deny dialog)
notifications/data (model · api · store merging REST + SignalR) · pages (inbox) · ui (item)

Pattern guarantees

Smart pages→ Stores (signal/computed)→ Api services (HTTP only)⇄ Interceptors: Bearer → AppError → GET retry⇄ Guards: requireAuth / requireAdmin / requireUser / guestOnly→ Lazy routes (loadChildren / loadComponent)
