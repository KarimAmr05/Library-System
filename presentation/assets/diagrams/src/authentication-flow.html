Authentication & Authorization — JWT end-to-end

Actual implementation on both tiers · PBKDF2 password hashing · role claims · functional guards + Bearer interceptor

Sign-in (issuing the token)

1
User submits email + passwordAngular reactive form → AuthService.login()
2
POST /api/auth/loginno token required; anonymous attribute
3
Backend verifies credentialsPBKDF2-SHA256 verify (100k iterations, per-user salt) · generic failure message (anti-enumeration) 401 on mismatch
4
JwtService.GenerateTokenHMAC-SHA256 · claims: sub, email, nameidentifier, role · 120-minute expiry · issuer/audience validation
5
Frontend stores the JWTlocalStorage + decoded AuthStore signals (currentUser / role / isAuthenticated)

Calling a protected API

6
Route guard checks firstrequireAuth / requireAdmin / requireUser — UX only, server remains authoritative
7

8
Backend validates the JWTsignature, issuer, audience, lifetime (30s clock skew)
9
Role authorization[Authorize(Roles="User")] → borrow, my-requests · [Authorize(Roles="Admin")] → review queue, approve/deny 403 when wrong role
10
